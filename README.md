# TOEIC hằng ngày

Trang web tĩnh để học từ vựng TOEIC: 4 từ mới mỗi ngày, test Part 5 từ các từ đã học, giải thích đáp án bằng tiếng Việt.

- Nhập tên là học được, không cần đăng nhập.
- Tiến độ lưu trên trình duyệt của từng người (localStorage).
- Tab "Tiến độ": học viên sao chép mã gửi cho người quản lý, người quản lý dán mã để xem từ đã học, câu sai, tiến bộ theo ngày.

## Đưa lên GitHub Pages

1. Tạo kho mới trên github.com (Repository name tùy ý, để Public).
2. Bấm "uploading an existing file", kéo `index.html`, `.nojekyll` và `README.md` vào, rồi Commit.
3. Vào Settings → Pages. Ở Source chọn "Deploy from a branch", Branch chọn `main`, thư mục `/ (root)`, bấm Save.
4. Đợi 1-2 phút. Link có dạng `https://TEN-GITHUB.github.io/TEN-KHO/`.

## Cập nhật nội dung

Sửa `index.html` (thêm từ ở mảng `W` đầu phần script), rồi tải lên lại cùng kho. Link giữ nguyên.
